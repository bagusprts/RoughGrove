# RoughGrove

RoughGrove enables high-performance real-time data processing and auto-scaling across distributed clusters with dynamic load balancing and service orchestration.

The key benefits of using RoughGrove include:

- RoughGrove enables high-performance real-time data
- processing and auto-scaling across distributed
- clusters with dynamic load balancing

## Installation

1. Clone the repository: `git clone https://github.com/innayakendya/RoughGrove.git`
2. `cd RoughGrove`
3. Install in editable mode: `pip install -e .`

## Configuration

To configure RoughGrove, modify the settings in the configuration file. Options include:
- **DEBUG**: Enable or disable debug mode.
- **ALLOWED_HOSTS**: Set allowed hostnames.
- **DATABASES**: Configure database settings.
